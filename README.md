# RX Remote (Android, IR)
Native shell + WebView. UI = app/src/main/assets/index.html (also holds the IR spec JSON).
1. Android Studio ile bu klasoru ac (Gradle wrapper'i Studio kurar).
2. IR vericili telefonu USB ile bagla, Run.
3. Her tusu kendi Samsung TV'nde dene; kodlar modele gore degisebilir (spec -> ir.caveats).
Not: IR gonderimi sadece gercek cihazda calisir, emulatorde calismaz.
